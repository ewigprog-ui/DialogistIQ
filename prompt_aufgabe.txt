# ТЗ на разработку MVP: Desktop-приложение "Aegis Writer" (Сценарно-писательский редактор с поддержкой AI)

## Цель проекта
Создать кроссплатформенное десктопное приложение (MVP) для писателей и сценаристов с гибридной поддержкой ИИ (облачные API + локальные модели через Ollama).

## Стек технологий
- **Фреймворк:** Tauri (Rust бэкенд + React/TypeScript фронтенд) или Electron + React (на выбор агента, ориентируясь на скорость старта и легковесность).
- **UI-библиотека:** Tailwind CSS + shadcn/ui (или аналогичные чистые компоненты).
- **Стейт-менеджмент:** Zustand.
- **Хранилище:** Локальная файловая система (структура проекта в виде директории с JSON/Markdown файлами).

## Ключевые требования к функционалу (MVP)

### 1. Управление проектом (Workspace & Binder)
- Создание проекта (название, тип: Сценарий / Роман).
- Боковая панель со структурой дерева:
  - Папка "Сюжет / Главы / Сцены"
  - Папка "Персонажи"
  - Папка "Мир / Заметки"
- Возможность создания, переименования, удаления и перетаскивания элементов (drag-and-drop).

### 2. Текстовый редактор
- Центральная область редактирования (использовать TipTap или Monaco Editor с поддержкой Markdown / Fountain-подобной разметки).
- Подсчет слов, символов, времени чтения / хронометража сценария (1 страница = 1 минута экрана).

### 3. Модуль интеграции с ИИ (AI Service Layer)
- Создать единый интерфейс `AIService`, поддерживающий три провайдера:
  1. **OpenAI API** (GPT-4o / GPT-4o-mini)
  2. **Anthropic API** (Claude 3.5 Sonnet)
  3. **Local Ollama** (endpoint по умолчанию `http://localhost:11434/v1`)
- Настройки приложения (Settings Modal):
  - Вывод полей ввода API-ключей (безопасное хранение в Tauri Store / OS Keytar).
  - Выбор активной модели для текущей задачи (например, выбор локальной модели из списка доступных в Ollama).

### 4. ИИ-ассистент в редакторе (AI Sidebar / Commands)
- Боковая панель чата с ИИ, имеющая доступ к текущему открытому тексту сцены.
- Горячие клавиши / контекстное меню для выделенного текста:
  - "Продолжить сцену"
  - "Переписать диалог более естественно"
  - "Проверить на логические ошибки"
- Стриминг ответов ИИ (Server-Sent Events / ReadableStream) в реальном времени.

## Структура файлов проекта, которую нужно сгенерировать
1. `/src-tauri` (или корень Electron) — настройки окна и файловой системы.
2. `/src/components` — основные UI-блоки (Sidebar, Editor, AISidebar, SettingsModal).
3. `/src/services/ai` — модули подключения к OpenAI, Anthropic и Ollama.
4. `/src/store` — состояние проекта и настроек пользователя.

Начни с инициализации структуры проекта и реализации базового интерфейса с редактором текста и работающим подключением к Ollama/OpenAI API.
